# Business First — Digital Business Starter Kit

A complete **website template for small businesses** going digital — with services showcase, transparent pricing, testimonials, live payment integration, and an admin panel.

## What It Does

Gives small businesses a professional web presence out of the box — customers can browse services, read testimonials, see pricing, and pay directly on the site. The admin panel and JSON config make updates easy without touching code.

## Key Features

- **Services section** — showcase what your business offers
- **Transparent pricing** — clear pricing cards for each service tier
- **Testimonials** — social proof from real customers
- **Contact form** — direct inquiry capture
- **Razorpay live payments** — accept real payments directly on the site
- **Admin panel** (`admin.html`) — manage content without a developer
- **Kit page** (`kit.html`) — business starter kit bundle page
- **JSON-configurable settings** (`business-first-settings.json`) — update social links, business info, and branding without editing HTML
- **Operated under** health@nosh7.com

## Tech Stack

- HTML, CSS, Vanilla JavaScript
- Razorpay Payment Gateway
